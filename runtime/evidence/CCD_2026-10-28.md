## 4. 精度校核

### 设计点（9 点，模型内）

### 验证点（2 点，模型外校核）

| 验证点 | SiO2 / Si3N4 | 实测 | 模型预测 | 误差 |
|---|---|---:|---:|---:|

两个验证点误差同量级且符号相反，说明模型无系统性偏移，**外推可信**。

## 5. 结论

1. **两个因子均极显著**（P = 0.000）：氮化硅厚度（F = 6035）影响远大于氧化硅厚度（F = 1817）。
2. **交互项显著**（P = 0.035）：两者非独立作用，需按曲面而非单因子优化。
3. **平方项不显著**（P = 0.291）：响应面在设计域内**近似平面**，无明显的极值穹顶。
4. **方向性**：增大氮化硅厚度、减小氧化硅厚度 → 平均应力上升。
   - 最大：55.185 MPa @ SiO₂=100 nm, Si₃N₄=400 nm
   - 最小：55.149 MPa @ SiO₂=300 nm, Si₃N₄=200 nm
5. 全部响应落在 55.149–55.185 MPa 的**极窄带**（≈0.065 MPa）内，
   R² = 99.96% 说明模型拟合很好，但也意味着**工艺对该应力组合不敏感**，
   若目标是显著改变应力，需超出当前设计窗口。

## 7. 本次确立的 COM 规则（已写入 SKILL.md / README.md / 知识库）

按"发现顺序"列出，每一条都曾导致数十分钟的盲试：

1. **`UserInterface.Visible` 默认 `False`（无头）→ 命令被静默丢弃**。
   现象：提交后 `Commands.Count` 不动、不报错、也不执行。
2. **`DisplayAlerts=False` 会吞错并永久卡死队列**。
   现象：一条出错命令之后，所有命令都返回「正忙于处理操作」。
   保持 `True` 时错误会以 `Syntax Error` 登记为命令名，可据此迭代。
3. **`CONTOURPLOT` / `SURFACEPLOT` 必须用星号**：`C5*C4*C3`（z\*y\*x），空格 → Syntax Error。
   命令名是 `SURFACEPLOT`，**没有** `SURFPLOT`。
4. **`RSREG` 的 `TERMS` 是必需子命令**（报「TERMS 是所要求的子命令」）。
5. **`RSREG` 没有 `FIT` 子命令**（报「子命令 FIT 失序」）→ 用 `FITS C6`。
6. **`RSREG` 没有 `CONTOUR`/`SURFACE` 子命令**（报「子命令 CONT 失序」）
   → 模型等值线用 `CONTOURPLOT` 画拟合值列。
7. **`TSMMARY` 是拼写错误，正确为 `TSUMMARY`**（截断成 `TSMM` 报「失序」）。
8. **`EXECUTE "*.MAC"` 不能用来跑 GMACRO 宏**（报「未知 Minitab 命令: GMAC」）；
   宏应用 `%NAME` 调用。
9. **对象模型差异**：无 `Cells`；列名用 `Name`（`Label` 只读）；
   工作表列数初始为 0，需 `Columns.Add(Quantity=n)`；
   `SetData` 是整体替换且不接受 `None`。
10. **输出读取因版本而异**：Mtb 20 用 `OutputDocument.Text`，Mtb 22 旧记录用 `Outputs.Item(k).Text`。

## 8. 方法论要点：为什么"用户复制弹窗"是关键

Agent 侧对 Minitab 只有 COM 一个观察通道，而**模态弹窗的内容不在 COM 里**。
本次 7 条语法类错误中，有 3 条（第 4、5、6 条）是**用户手动复制弹窗原文**后一次性定位的；
在此之前 Agent 只能看到"挂起"，无法区分是语法错、弹窗阻塞还是真的在算。

因此 `README.md` 已把「弹出报错时请手动复制给 Agent」列为**使用前必读**。
